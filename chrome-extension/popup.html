🚀 SessionForge Import

Before you start

SessionForge Import copies a login from Chrome into the SessionForge desktop app on this computer.

  • What it reads: the cookies and localStorage of the site you send, and that page's URL, title and favicon URL (if the title contains an e-mail address, SessionForge names the session after it). A “Send to <session>” button for a SessionForge sign-in request reads only the cookies of the domains shown on it.
  • When: only when you click a Send button. Nothing is read in the background.
  • Where it goes: only to the SessionForge app on this computer (http://127.0.0.1:34567). Never to us or any other server. No analytics. To tell you about new SessionForge desktop versions, it also asks GitHub (api.github.com) for the latest version number at most once a day; nothing about you or your logins is sent.
  • Site access: the first time you send from a site, Chrome asks you to allow access to that site.
  • What it stores: this choice, and until Chrome closes, the site it last asked access for.
  • How to stop: remove site access in chrome://extensions → SessionForge Import → Details → Site access, or uninstall the extension.
