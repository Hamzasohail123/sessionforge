Extension troubleshooting

The common popup messages and how to fix them.

MessageWhat to do
SessionForge is not running (could not reach 127.0.0.1:34567)Start SessionForge; check that nothing else uses port 34567
Chrome did not allow access to …, so nothing was sentClick Send again and allow access, or click Allow access in a tab
Only http(s) pages can be sentThe tab is a chrome:// page, the Web Store or a file; open the site itself
Session too large to import (over 5 MB)Import from a page with less localStorage, or log in inside SessionForge
This request expired or was already usedClick Sign in with Chrome in SessionForge again
No "Send to <session>" buttonUpdate or reload the extension (1.2.0 or later); check that SessionForge uses port 34567
Imported but not logged inThe site keeps its login elsewhere (IndexedDB, sessionStorage). Log in once inside SessionForge

All messages: chrome-extension/README.md.
