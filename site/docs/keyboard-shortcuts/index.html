Keyboard shortcuts

Shortcuts work both in the SessionForge toolbar and inside pages, and act on the focused pane. Cmd on macOS, Ctrl elsewhere; Ctrl+Tab is Ctrl on every OS.

ShortcutAction
Cmd/Ctrl+KCommand palette
Cmd/Ctrl+,Open Settings
Cmd/Ctrl+TNew tab
Cmd/Ctrl+WClose tab
Cmd/Ctrl+Shift+TReopen closed tab or session
Ctrl+Tab / Ctrl+Shift+TabNext / previous tab
Cmd/Ctrl+1–4Focus pane 1–4
Cmd/Ctrl+LFocus address bar
Cmd/Ctrl+R, F5Reload
Cmd/Ctrl+Shift+R, Shift+F5Hard reload (ignore cache)
Alt+Left / Alt+RightBack / forward
EscapeStop loading (while a page loads; otherwise the page gets it)
F12, Cmd/Ctrl+Shift+IToggle DevTools
Cmd/Ctrl+Shift+JDevTools console
Cmd/Ctrl+Shift+CInspect element
Cmd/Ctrl+UView page source

A combination with extra modifiers (for example Ctrl+Shift+K) goes to the page. The SessionForge window's own DevTools are in the menu (press Alt, then View → Toggle Developer Tools).
