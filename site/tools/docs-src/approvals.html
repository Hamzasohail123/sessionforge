Each preset shows the exact text to paste. Apply edits the file for you after a preview: it makes a <file>.bak-YYYYMMDD-HHmmss backup, changes only SessionForge entries, keeps comments, and never writes the token. SessionForge's own limits (Hidden/Read/Control, read-only production, Stop) apply whatever you choose.

Files

  • Cursor: ~/.cursor/permissions.json, mcpAllowlist. Once this key exists, Cursor uses it instead of the allowlist in Cursor Settings, so tools you allowed there for other servers ask again.
  • Claude Code: ~/.claude/settings.json, permissions.allow entries mcp__sessionforge__<tool>.
  • Codex: default_tools_approval_mode in [mcp_servers.sessionforge] of ~/.codex/config.toml. Restart Codex afterwards.
