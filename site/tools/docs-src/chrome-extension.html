How it works

  1. Log in to a site in Chrome as usual.
  2. Click the SessionForge Import icon. The first time, a short notice explains what it reads, when, where it goes and how to stop it. Nothing is read or sent until you click Agree.
  3. Click Send to SessionForge. The first time you send from a site, Chrome asks you to allow access to that site.
  4. SessionForge names the session after the e-mail address in the tab title, or else the hostname, and opens the URL in a free pane.

Not copied: sessionStorage, IndexedDB, history, bookmarks, saved passwords. Cookies without an expiry date are kept for 30 days, so imported logins survive a restart.

Install

Install it from the Chrome Web Store. To work on the extension, load it unpacked:

  1. Get the chrome-extension/ folder (clone the repo, or download the source zip from the release).
  2. Open chrome://extensions/ and turn on Developer mode.
  3. Click Load unpacked and select the folder.

Built and tested for Chrome. Edge and Brave should work but are untested. Firefox is not supported. Every popup state, with pictures: the extension page.
