Set up

git clone https://github.com/Hamzasohail123/sessionforge.git
cd sessionforge
npm install
npm run rebuild:native
npm run electron:dev

Tests

npm run test:e2e

This builds the app and runs the Playwright suite: unit specs and Electron end-to-end specs, with a temporary profile and a local test server. Run the unit specs alone with npx playwright test --project=unit.

Code style, commit conventions and the review process: CONTRIBUTING.md and DEVELOPMENT.md.
