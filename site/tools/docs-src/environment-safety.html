What production changes

  • A red PROD label in the session bar and in the pane header.
  • Agents get read-only access unless you confirm by typing the session name in Settings → MCP Server / Agent Bridge. The confirmation lasts until SessionForge restarts.
  • The environment can't be changed after a session is created, so a production session can't lose this protection. Renaming keeps it, and a closed production session comes back read-only for agents.
