1. Create a session. Click the + (New session) button, name it (for example "Admin"), pick a colour and environment.
  2. Log in. Go to your app and log in as that role.
  3. Open split view. Pick a layout with the layout buttons at the right of the session bar.
  4. Create another session. Repeat for "Customer" or other roles.
  5. Send a login from Chrome. In Chrome, click the SessionForge Import extension → Send to SessionForge. The login opens in a new session, in a pane.

The first-run tour

On a new install, SessionForge shows a short tour of split view, Settings and the MCP server once. Skip tour or Escape ends it. Replay it from Settings → General → Show tour again.
