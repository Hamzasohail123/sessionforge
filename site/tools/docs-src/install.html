macOS first launch

The app is ad-hoc signed but not notarized (there is no Apple Developer account yet), so macOS blocks the first open. Drag SessionForge to Applications and open it once. Then either click Open Anyway in System Settings → Privacy & Security (required on macOS 15 and later), or run:

xattr -dr com.apple.quarantine /Applications/SessionForge.app

Windows first launch

The installer is unsigned, so SmartScreen shows "Windows protected your PC". Click More info → Run anyway.

Linux

On Ubuntu 23.10 and later, use the .deb. Its install script sets up Chromium's sandbox helper, so the app starts with the sandbox on.

sudo apt install ./SessionForge-*-linux-amd64.deb

The AppImage works on distributions that allow unprivileged user namespaces:

chmod +x SessionForge-*.AppImage && ./SessionForge-*.AppImage

Avoid --no-sandbox. On Ubuntu 23.10 and later AppArmor blocks those namespaces and the AppImage exits with a SUID sandbox error. --no-sandbox starts it, but turns off Chromium's sandbox for every page you open. Prefer the .deb.

Run from source

Needs Node.js 20 or 22, npm and git. On macOS run xcode-select --install once; on Windows install the "Desktop development with C++" workload of Visual Studio Build Tools if rebuild:native asks for it.

git clone https://github.com/Hamzasohail123/sessionforge
cd sessionforge
npm install
npm run rebuild:native
npm run electron:dev
