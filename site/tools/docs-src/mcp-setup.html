1. Turn on the server

Open Settings (gear icon or Cmd/Ctrl+,) → MCP Server / Agent Bridge and turn on Enable MCP server.

2. Export the token

Click Copy export line and add it to ~/.bashrc or ~/.zshrc:

export SESSIONFORGE_TOKEN='sfa_…'

3. Add the server to your editor

The panel shows the same snippets with your real port and path.

Cursor

.cursor/mcp.json in a project, or ~/.cursor/mcp.json for all projects:

{
  "mcpServers": {
    "sessionforge": {
      "url": "http://127.0.0.1:34568/mcp",
      "headers": {
        "Authorization": "Bearer ${env:SESSIONFORGE_TOKEN}"
      }
    }
  }
}

Codex

The CLI, VS Code extension and app share ~/.codex/config.toml:

[mcp_servers.sessionforge]
url = "http://127.0.0.1:34568/mcp"
bearer_token_env_var = "SESSIONFORGE_TOKEN"

Claude Code

Run once. Keep the single quotes: they store ${SESSIONFORGE_TOKEN} literally, so the token never lands in ~/.claude.json.

claude mcp add --transport http --scope user sessionforge http://127.0.0.1:34568/mcp --header 'Authorization: Bearer ${SESSIONFORGE_TOKEN}'

4. Restart and check

Restart the editor from a shell that has SESSIONFORGE_TOKEN (or log out and in). Then check that the tools are listed:

  • Cursor: Settings → MCP.
  • Codex: codex mcp list, or /mcp in the chat.
  • Claude Code: claude mcp list should say "✔ Connected", or /mcp in a session.

Optional: give your agent the rules in docs/agents/sessionforge.md.
