ToolAccessWhat it does
list_sessionsReadYour sessions (already logged in) with their tabs and your access. Call it first.
openControlOpen a URL in a session and show it in a pane.
navigateControlNavigate a session tab to a URL.
backControlGo back in a session tab's history.
reloadControlReload a session tab.
snapshotReadA compact page outline with element refs for click, type, select and press.
clickControlClick an element (ref or CSS selector) with a real mouse event.
typeControlType into a text field; optionally press Enter.
selectControlChoose options of a <select> by value or label.
pressControlPress one key, optionally with modifiers.
wait_forReadWait for text, a selector, a URL or network idle.
screenshotReadPNG of a session tab, or of all panes. For visual checks.
console_logsReadConsole messages of a session tab since the bridge was enabled.
network_logReadRequests of a session tab with status and timing; secret headers redacted.
send_request_asRead for GET, HEAD, OPTIONS; Control for othersSend one HTTP request as several sessions and compare the answers.
get_layoutReadThe split layout: mode, active pane, what each pane shows.
set_layoutControlChange the layout mode, which session each pane shows, and the focused pane.

A typical flow

  1. list_sessions → see Admin and Customer and your access to each.
  2. open { session: "Admin", url: "http://localhost:3000/billing" }.
  3. snapshot { session: "Admin" } → find refs such as [ref=e12].
  4. click { session: "Admin", ref: "e12" }.
  5. send_request_as { sessions: ["Admin", "Customer"], include_no_session: true, url: "http://localhost:3000/api/billing" } → one column per role, with a summary of what differs.

Not available: arbitrary JavaScript, file uploads, downloads, CDP, cross-origin iframes. snapshot does not look inside closed shadow DOM.
