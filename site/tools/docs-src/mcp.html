An agent can list your sessions, open pages in panes, read a compact page outline with element refs, click and type with real input events, read console and network logs, take screenshots, change the split layout, and send one HTTP request as several roles to compare what each gets. SessionForge has no AI of its own.

Defaults

  • Off until you turn on Enable MCP server in Settings → MCP Server / Agent Bridge.
  • New sessions start at Read access. Production sessions are read-only.
  • Set SESSIONFORGE_MCP_PORT to use another port.

Limitations

The MCP server first shipped in v0.1.0. It has no arbitrary JavaScript, file uploads, downloads or cross-origin iframe support.
