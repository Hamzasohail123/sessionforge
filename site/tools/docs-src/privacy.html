• No analytics, usage statistics, crash reports, telemetry, accounts or cloud sync.
  • One update check a day: an HTTPS GET to GitHub's latest-release API with the User-Agent SessionForge/<version>, no cookies or identifiers. Turn it off in Settings → General → Check for updates.
  • When an agent calls send_request_as, SessionForge sends that request, to the URL the agent chose, with the cookies of the sessions it named.

Stored on your computer

Session data (cookies, localStorage, IndexedDB, cache) and a local SQLite database with names, colours and tabs. The Agent Bridge token is stored encrypted with the OS keyring. The activity log and the console and network logs that agents read live in memory only.

This website has no analytics or cookies either. Full policy: PRIVACY.md.
