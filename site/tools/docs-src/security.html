Report a vulnerability

Use GitHub Security Advisories. You should receive a response within 48 hours. The project follows a 90-day disclosure timeline. Supported: 0.1.x.

Best practices

  • Keep it updated from GitHub Releases. SessionForge tells you about new versions; it does not install them.
  • Use OS-level disk encryption.
  • Log out of production sessions when you are not testing.

Known limits

  • Local malware with your user's rights can read session data.
  • Agents act with the session's real cookies.
  • Closed shadow DOM and cross-origin iframes are not inspected by snapshot.
