Claude Code

Remove an HTTP entry first with claude mcp remove sessionforge; the name must come before --env:

claude mcp add sessionforge --transport stdio --scope user --env 'SESSIONFORGE_TOKEN=${SESSIONFORGE_TOKEN}' -- node '<path>/sessionforge-mcp.mjs'

Without Node

Use the SessionForge executable as command and add ELECTRON_RUN_AS_NODE=1 to the server's environment. Packaged builds keep the bridge in resources/bin/.
